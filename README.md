# Guía local de Cancún

Una guía práctica para personas que vienen a Cancún, ya sea por uno de nuestros eventos o por viaje personal. Aquí encontrarás recomendaciones concretas: cómo moverte, dónde quedarte, qué planes valen la pena y cómo evitar errores comunes.

> Esta no pretende ser una guía turística genérica. La iremos construyendo con recomendaciones locales, contexto útil y detalles que realmente ayuden a planear el viaje.

## Cómo usar esta guía

Cada recomendación buscará responder:

- Para quién es buena opción.
- Dónde está y cómo llegar.
- Cuánto cuesta aproximadamente.
- Cuándo conviene ir.
- Qué hacer, pedir o evitar.
- Un tip local que no suele aparecer en las guías tradicionales.
